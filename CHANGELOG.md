## [1.0.0] - 2026-07-31

### Added

- Android audio download workflow.
- Download queue management.
- MP3 conversion through FFmpeg.
- Configurable MP3 bitrate.
- Configurable download folder.
- MP3 metadata editor.
- Quick title formatting.
- Configurable title-noise filters.
- Comparison-folder indexing.
- Duplicate-title warnings.
- Song waiting list.
- Important and completed note states.
- Bulk deletion of completed notes.
- In-app YouTube search.
- Light, dark, and system themes.
- Wireless ADB development scripts.
- Public repository documentation.
- GitHub issue templates.
- Pull request template.
- GitHub Actions Android build workflow.
- Dependabot configuration.

### Fixed

- Unicode decorative-symbol removal.
- Unsafe regular-expression handling.
- Tag editor state restoration.
- ADB Wi-Fi target validation.
- PowerShell terminal encoding issues.
- Duplicate note detection behavior.
- File deletion and tag editor state synchronization.
