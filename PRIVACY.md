# Privacy Policy

Effective date: 2026-07-31

## Overview

GetMP3 is designed as a local-first Android application.

The official project does not require mandatory account registration and does not operate a user-profile backend.

## Data stored on the device

Depending on the features used, GetMP3 may store:

- Application settings.
- Selected folder URIs and display names.
- Song notes.
- Note completion and importance states.
- Download queue information.
- Indexed artist names.
- Indexed album names.
- MP3 metadata read from user-selected files.
- Temporary processing files.

This information is stored locally in application storage or in folders explicitly selected by the user.

## Network activity

GetMP3 uses network access when required by a user action, including:

- Searching for publicly available video information.
- Resolving a supported URL.
- Downloading media selected by the user.
- Retrieving thumbnail information.
- Retrieving metadata information.

Third-party platforms and libraries may process these requests. Their own privacy policies and terms may apply.

## Folder and file access

GetMP3 accesses:

- Its private application storage.
- Android media collections when permitted.
- Folders explicitly selected by the user through Android's Storage Access Framework.

The application should not scan unrelated folders without user action.

## Accounts, advertising, and analytics

The official project does not require a GetMP3 account.

The maintained source tree is not intended to contain advertising SDKs, third-party tracking SDKs, or a project-operated analytics backend.

Anyone distributing a modified build must disclose any analytics, tracking, or advertising they add.

## Data sharing

GetMP3 does not sell user data.

Network requests initiated by the user may necessarily transmit:

- Search terms.
- Selected URLs.
- IP address.
- Standard connection information.
- Platform request metadata.

This information may be received by the relevant third-party service.

## Data deletion

Users can remove locally stored information by:

- Deleting individual notes.
- Deleting completed notes.
- Clearing application storage in Android settings.
- Uninstalling the application.
- Deleting generated media files from the selected folder.

Uninstalling GetMP3 does not automatically remove files saved to public or user-selected folders.

## Permissions

Permissions are requested only when required by a feature.

Android may display permission prompts for notifications, media access, folder access, or background processing.

## Changes

This policy may be updated when application behavior changes.

Material privacy changes should also be documented in `CHANGELOG.md`.

## Contact

Privacy questions may be submitted through the GitHub issue tracker.

Security-sensitive reports must follow `SECURITY.md`.
