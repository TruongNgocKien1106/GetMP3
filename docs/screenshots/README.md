# Screenshots

Place sanitized real-device screenshots in this directory.

Recommended files:

```text
download.png
waiting-list.png
youtube-search.png
tag-editor.png
settings.png
```

Before committing a screenshot, remove:

- Notifications.
- Phone numbers.
- Email addresses.
- Account names.
- IP addresses.
- ADB ports.
- Private URLs.
- Private filenames.
- Personal media information.

Recommended presentation:

- Use one consistent theme.
- Use the same device resolution.
- Show realistic non-sensitive sample data.
- Crop to the application or device frame.
- Avoid including Android Studio in product screenshots.
